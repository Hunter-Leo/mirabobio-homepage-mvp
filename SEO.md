# SEO Guide for MiRABO Biotechnology Website

## Submit to Search Engines

### 1. Google Search Console

1. Visit https://search.google.com/search-console
2. Add property: `mirabobio.com`
3. Verify ownership (HTML tag or DNS verification)
4. Submit sitemap: `https://mirabobio.com/sitemap.xml`

### 2. Bing Webmaster Tools

1. Visit https://www.bing.com/webmasters
2. Add site: `mirabobio.com`
3. Verify ownership
4. Submit sitemap: `https://mirabobio.com/sitemap.xml`

### 3. Baidu Webmaster (Optional - for China market)

1. Visit https://ziyuan.baidu.com
2. Add website
3. Verify ownership
4. Submit sitemap

### 4. Naver Webmaster Tools (for Korea market)

1. Visit https://searchadvisor.naver.com
2. Sign in with Naver account
3. Add site: `mirabobio.com`
4. Verify ownership (HTML file upload or meta tag)
5. Submit sitemap: `https://mirabobio.com/sitemap.xml`
6. Request site collection (사이트 수집 요청)

## Domain Configuration

**Primary Domain:** `mirabobio.com` (without www)

**DNS Configuration:**
- `mirabobio.com` → CNAME to `mirabobio-homepage-mvp.pages.dev`
- `www.mirabobio.com` → CNAME to `mirabobio-homepage-mvp.pages.dev`

Cloudflare Pages automatically redirects `www.mirabobio.com` to `mirabobio.com`.

## SEO Best Practices

### On-Page SEO ✅

- Unique title tags for each page
- Meta descriptions (150-160 characters)
- Proper heading hierarchy (H1, H2, H3)
- Alt text for images
- Internal linking
- Mobile-friendly design
- Fast page load speed

### Technical SEO ✅

- SSL certificate (HTTPS)
- XML sitemap
- robots.txt
- Canonical URLs
- Structured data (JSON-LD)
- Clean URL structure

### Content SEO

- Original, high-quality content
- Keyword optimization (natural usage)
- Regular content updates
- Industry-relevant information
