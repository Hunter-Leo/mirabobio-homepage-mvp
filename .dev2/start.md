# Specify
我想重新优化当前网站设计和主题,需要体现高科技风格, 用能够拿设计奖的效果来重新设计当前网站,包括需要增加更多视觉元素,整体设计需要更融洽. 

# Plan
1. 请先根据材料内容来设计公司主页的内容，包括首页、关于我们、产品服务、案例研究、联系我们等页面， 包括排版、图片、文字等元素；
2. 完成公司主页的内容设计文档（.dev2/generated/homepage-content-design.md）, 需要对公司logo/行业/材料内容进行分析，描述清楚网站设计风格指南，有几个页面， 每个页面的详细设计（包括怎么排版、哪个位置准备用什么图片、用什么图标、文字、视觉效果等元素）；
2. 请设计项目结构，包括文件夹和文件的组织方式，技术栈要求，完成项目设计文档（.dev2/generated/project-design.md）；
3. 请根据项目设计文档和内容设计文档，创建任务文档（.dev2/generated/tasks.md）， 每个任务需要描述清楚，包括任务的具体内容、任务需要用的参考来源文件引用、如果是页面设计，页面设计的主题等等。 还需要创建任务状态列表，用于执行过程中更新任务状态；
4. 创建任务启动与恢复文档（.dev2/generated/start-and-resume.md）， 描述清楚如何开始或继续执行任务文档，并且需要注明设计要求/规范，编码要求/规范， 声明下述*重要事项内容*，执行过程与规范（必须体现:当前执行步骤->正在查找文档->正在执行->更新任务状态）。请要求开发人员，开发过程中，每完成一个页面功能模块的开发， 都必须通过 playwright 工具来检查页面实际效果与设计文档间是否有出入。
